    01 / EL PUNTO DE PARTIDA

    Un proceso que pedía orden

    Archivos Word, convenios en PDF y documentos guardados como adjuntos de Outlook. El proyecto original nació para preparar esos archivos, buscar un logotipo y organizar carpetas.

    Sus seis scripts de Python son la base de esta aplicación. La nueva versión conecta esas tareas en una experiencia que permite seleccionar archivos, seguir el avance y revisar resultados.

    02 / EL RECORRIDO

    Preparar. Reconocer. Revisar.

    1. OrganizarInventario, conversión y extracción de adjuntos.
    2. ReconocerComparación de características visuales con SIFT.
    3. Revisar resultadosClasificación sugerida, evidencias y reporte Excel.

    Un alcance claro

    Una ayuda para la revisión documental

    Esta versión reconoce logotipos en imágenes incrustadas en PDF. La clasificación es una sugerencia: no valida firmas ni la validez de un convenio y no extrae texto. Los casos incompletos se señalan para revisión manual.

    Construido con PythonFastAPI · OpenCV · PyMuPDF · openpyxl
